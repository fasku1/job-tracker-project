# Job Tracker

A full-stack job application tracker that helps you manage and organize job applications in one place.  
Built with a Node.js backend and a modern frontend, with a simple Makefile to streamline local development.

---

## 🚀 Features
- Track job applications and statuses
- Full-stack setup (frontend + backend)
- Simple local dev workflow using `make`
- Live backend logs
- Easy start/stop commands

---

## 🛠 Tech Stack
**Backend**
- Node.js
- Express (assumed)
- npm

**Frontend**
- JavaScript / modern frontend framework
- Vite-style dev server (`npm run dev`)

**Tooling**
- Makefile for dev workflow
- nodemon (optional, for backend dev)
